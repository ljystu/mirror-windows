# Mirror Windows

A Chrome extension: every window shows the same tabs, in the same order. Open a tab in any
window and the live page moves there, with your typing, scroll position and video intact.
The other windows keep a stand-in tab for it (a blurred preview, if you turn page previews on).

- Same tabs and order in every window, including new ones; pinned tabs and tab groups too
- New tab, close, reorder and Cmd/Ctrl+Shift+T are mirrored everywhere
- The tab list survives a browser restart
- Toolbar button turns mirroring on and off; right-click it for a window that isn't mirrored
- Optional (settings, off by default): tabs in a group go back to the page they had when they joined the group when you collapse the group, or close it and open it again
- Everything stays on your computer: no network requests, no analytics, no account

## Install

Chrome Web Store: https://chromewebstore.google.com/detail/njpjahfldkekolkeckgnpbggoadogepe

From source: open `chrome://extensions`, turn on Developer mode, click "Load unpacked" and
pick the `extension` folder.
